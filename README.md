# SmartAgriTech

### AI-Powered Smart Farming Assistance Platform

**Project Status: Under Development**

SmartAgriTech is an AI-powered web platform designed to help farmers make informed agricultural decisions through multilingual support, voice assistance, and AI-based services.

## Project Objectives
- Provide accessible agricultural information.
- Support multiple regional languages.
- Assist farmers through AI-powered guidance.
- Improve access to agricultural resources.

##  Implemented Features
- Multilingual language selection.
- AI-powered farming assistant using Gemini API.
- Voice guidance in regional languages.
- Persistent AI chat history using PostgreSQL.
- Spring Boot backend integration.

## Planned Features
- Crop Recommendation.
- Plant Disease Detection.
- Weather Information.
- Government Scheme Assistance.
- Daily Market Prices.
- Expert Assistance.

## Technologies Used

| Frontend | HTML, CSS, JavaScript |
| Backend | Java, Spring Boot |
| Database | PostgreSQL |
| AI Integration | Gemini API |

## Project Structure
- `frontend/` – Website interface and resources.
- `backend/` – Spring Boot application and backend services.

## Current Development Status

This project is actively under development. Additional modules, testing, and improvements are planned.
